# Protect-the-earth
C言語で1年生の時に制作した2DShootingゲームです。授業で作成した2Dシューティングゲームをチームで改造しました

## ゲーム概要
**ジャンル：2Dシューティング

開発環境：C++/GSLIB**

## 担当箇所
**・プレイヤー**

プレイヤー(自機)の動きや死亡処理、弾発射、行動制限などを行いました。

**・敵2種類**

敵６種類のうちの２種類を担当しました。全方向(円状)に弾を撃つ敵、プレイヤーに向けて弾を撃つ敵を制作しました

**・UI**

タイトルロゴ、自機、敵などのUIの作成、配置をしました。
